Selected work

A closer look at the robotics software, tools, and systems I’ve worked on. These summaries describe my contributions across commercial fleets and research platforms.

01 / LOCALIZATION

Zone-aware ground autonomy

SteerAI / VentureOne

Scope

Localization subsystem control based on the robot’s active geographic zone.

Implementation

I built a modular C++ manager and ROS 2 interface for GeoJSON geofences, LLA-to-ENU coordinate conversion, active-zone detection, and localization subsystem control.

Software structure

I separated ROS wrappers from core libraries and built reusable coordinate-conversion and circular-buffer utilities.

ROS 2 · C++ · GeoJSON · GNSS / INS

02 / ROBOT HEALTH

Runtime monitoring & GNSS corrections

SteerAI / VentureOne

Health monitoring

I engineered DDS liveliness-based heartbeat infrastructure with reusable ROS 2 nodes, QoS policies, and component-failure callbacks.

GNSS corrections

I developed a C++ NTRIP client and forwarder, with diagnostics for internet, INS, and base-station connectivity.

DDS · QoS · C++ · NTRIP

03 / DEVELOPER TOOLING

ROS migration & regression testing

SteerAI / VentureOne

Migration tooling

I created a ROS 1 to ROS 2 rosbag converter supporting custom message mappings, topic remapping, and command-line workflows.

Regression workflow

I implemented scenario-driven bag playback, startup orchestration, and HTML test reporting for non-regression testing.

ROS 1 · ROS 2 · Rosbag · Test automation

04 / AUTONOMY

Coverage planning & localization

LionsBot International

Scale

I architected cross-platform C++/Python global coverage planning software for a fleet of more than 2,500 cleaning robots.

Mapping and localization

I maintained core mapping and localization components, adding real-time 2D map updates and robust initial-pose logic.

Production delivery

My work also included embedded drivers, production software release management, and contributions to IEC safety compliance for SC25/VP25.

C++ · Python · Coverage planning · SLAM

05 / MAPPING TOOLS

Desktop MapEditor & shared map data

LionsBot International

Ownership

I was the sole developer of a desktop 2D/3D map editor with point-cloud manipulation.

Build and delivery

I implemented automated builds for Linux, Windows, and macOS.

Map-data platform

I designed an annotation-rich file format shared by robots, desktop tools, and cloud systems. It was deployed across more than 2,000 robots.

2D / 3D · Point clouds · Linux · Windows · macOS

06 / RESEARCH ROBOTICS

Robots for maintenance & field work

ROAR Lab / SUTD · HuT Labs / Amrita University

Ship-hull maintenance and mosquito control

At ROAR Lab, I developed ROS control, hardware interfaces, and coverage-planning modules for the Hornbill ship-hull maintenance and Dragonfly mosquito-control robots.

Reconfigurable maintenance robots

As a Visiting Fellow at ROAR Lab, I designed software architecture for the Mantis façade-cleaning and Kiropter aircraft-exterior cleaning systems.

Agricultural robotics

At HuT Labs, I built software and control-system modules for the AMARAN coconut-climbing and harvesting robot.

ROS · Control systems · Coverage planning
